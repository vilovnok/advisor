# Backend
Этот модуль включает модуль, разработанный с использованием **FastAPI**. Он обеспечивает обработку запросов. Модуль легко масштабируется и настраивается для различных задач.


### Setup
Запустите backend сервер:
   ```bash
   poetry run python -m backend.main
   ```

API будет доступен по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).
