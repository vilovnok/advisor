# Frontend

Этот модуль, разработан с использованием **Angular**. Он предоставляет удобный пользовательский интерфейс для взаимодействия с системой.

### Setup
1. Вам нужно запустить docker-compose и этого в полне хватит, что Angular запустился.
2. Перейдите по адресу [http://localhost:4200](http://localhost:4200)
