# Advisor
---

**Advisor** — это система, предназначенная для предоставления персональных рекомендаций как кандидатам, так и HR-агентам. Основной целью проекта является автоматизация подбора наиболее подходящих вакансий или резюме на основе анализа входного контента.  

---

## 🛠 Основной функционал:

- **Персональные рекомендации**:
  - Для кандидатов: подбор топ-вакансий, соответствующих их навыкам и опыту.
  - Для HR-агентов: подбор резюме, соответствующих требованиям вакансии.

- **RAG-система (Retrieval-Augmented Generation)**:
  - Используется для обработки и анализа входных данных (резюме или вакансий).
  - Позволяет улучшить качество рекомендаций за счет интеграции данных из различных источников.

- **Анализ контента**:
  - Интеллектуальная обработка текстовых данных для выявления ключевых параметров, таких как навыки, опыт работы, требования вакансий и другие аспекты, отражающие профпригодность.

---

## 📈 Преимущества системы:

- Сокращение времени на поиск релевантных вакансий или резюме.
- Высокая точность рекомендаций благодаря использованию современных алгоритмов анализа данных.
- Удобство использования как для соискателей, так и для HR-агентов.

---

Advisor упрощает процесс трудоустройства и делает взаимодействие между кандидатами и работодателями более эффективным.

## Запустите необходимые

1. Поднять docker контейнеры
```bash
docker-compose up -d
```

2. Подгрузить зависимости
```bash
poetry install
```

3. Подгрузить данные с HH
Например, загрузить 100 вакансий и резюме
```bash
poetry run python scraper/main.py --topic "Devops разработчик" --area 1  --limit_page 4 --limit_objects 100
```

4. Преобразовать полученные данные в csv файлы
```bash
poetry run python scraper/forge_dataset.py
```

5. Создаем коллекцию для данных в Qdrant
```bash
poetry run python agent/database/main.py --act create --coll_name advisor_db
```

6. Загружаем преобразованные данные в Qdrant
```bash
poetry run python agent/database/main.py --act upload --coll_name advisor_db
```

7. Запускаем API для взаимодействия с агентом
```bash
poetry run python -m backend.main
```

8. Переходим по адресу [http://localhost:4200](http://localhost:4200)
